# Agent E — Mobile filename and Aiko SRT

**Source milestone:** proposed on `integration/agent-e-pilot-hardening-v1` from pinned `db96d5c1f96aabe15b16a472106758f79214417b`.

- **New mobile import:** File-picker imports create `Voice Archive/<original filename stem>.md`. A deterministic ID suffix protects collisions. `recording_id`, UUID, audio hash, playback asset and stable sidecar naming are unchanged. A repeated import or renamed human note is reused by ID, never renamed automatically. `source_title` records the full original filename while `display_title` omits the extension.
- **Aiko SRT:** `Innermaze: Import Aiko SRT for current recording` on iPhone and Mango. Select a `.srt` file after opening a recording in Innermaze. Its timestamps become `voice-archive-sync-v1` segment blocks and editable Markdown paragraphs. `words: []` marks that no word timestamps were supplied. `source: aiko` in sync and `transcription_source: aiko` in note frontmatter. Audio duration is read locally and captions beyond the recording end are refused.
- **Overwrite policy:** Pending/blank notes without timing sidecars import directly. Existing text, ready status or existing sidecars trigger an explicit user choice. On affirmative replacement, the previous note and previous sidecar (if any) are saved as `.txt` copies under `Voice Archive/Transcription Backups` before changes. iCloud conflicts detected during file selection cancel the import. Never modify playback audio, original Dropbox/Just Press Record archives, SQLite manifest or immutable recording ID.
- **Transcription alternatives:** Existing targeted Mango Whisper remains functional and unchanged. Aiko SRT import is fully local to Obsidian on iPhone; no Mango helper needed.
- **Tests:** The publisher runs the 21 existing development commands and 3 new Aiko/filename checks before committing. Unit and mock-integration tests are not equivalent to physical iPhone acceptance.
- **Required actual acceptance:** Import a newly created iPhone Voice Memo and verify human-readable note filename, player header, UUID, reimport, duplicate-name collision; open the recording, export SRT from Aiko, import via Obsidian command palette, play segment-aligned text, edit a paragraph, reimport SRT and cancel to verify non-overwrite; then explicitly back up/replace only when wanted. Check Mango Whisper remains accessible and no original archive file was changed.
